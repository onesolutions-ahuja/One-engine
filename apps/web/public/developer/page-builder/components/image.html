Smart Image

Show a product photograph

Bind the photo and caption, then compare placement, surface colours and fit in the illustrated lesson.

Design a Smart Image

  1. Insert Smart Image and select it. For a record photo, choose the object in Object Source and bind Image Source to the photo field, for example @Product.Photo. Bind Text Source to @Product.Name.
  2. Select the image area and open its Design properties. Under Image, use Placement to choose top, left, right or bottom. Set Image Width for a side image or Image Height for a stacked layout.
  3. Change the body and header fills separately. For the dark example, use #23483f for the surface and caption background and white for the caption text. Use Image Background Colour for the space around a fitted photo.
  4. Choose Fit to show the whole photo. Choose Fill to cover the image box by cropping its edges. Stretch scales the photo to the box dimensions and can distort it.

Available properties

Select the component on the canvas, then select the part you want to style. Expand a group below to find the property label, its inventory CSV ID and its listed choices. Use the exported layout inventory to match the component instance when uploading changes.
