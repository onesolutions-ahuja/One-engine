INSIDE ONEENGINE PAGE BUILDER

Design a component on the canvas

These screenshots show the running Page Builder with two sample Product records. Follow the blue selection outline, the active Design section on the left, and the field name beside the top formula bar.

1. Select the grid and choose its records

Open the Desktop page in Design mode. To start a new grid, use the Insert tab and choose Smart Card Grid. Click the grid on the canvas, then open Design → Object Source and choose Product. The two sample records here are Filter cartridge and Seal kit.

2. Bind the title and price where they appear

Click the yellow data icon beside the first card’s title. Check that the top bar says Card title, then enter @Product.Name. Repeat on the price field with the expression below. The binding applies to every tile, so the same expression displays £12.50 for the filter and £4.75 for the seal kit.

="£" & FORMAT(@Product.Price, "0.00")

3. Change the grid’s appearance

Click the empty area inside the grid’s blue outline. Open Design → Properties and check the target at the right of that row says Grid. Under Appearance, open the fill control and choose the background colour. The CSV example uses #eef5ef. To resize the whole component, drag a blue edge handle or open Dimensions & Alignment.

Use the save icon in the top toolbar to save the draft. Check both records and the layout before publishing it.

Apply the same design by CSV

Use one row per property. For an existing design, download the component inventory from the page list to get the exact page API name, component name, layout and property IDs. Download all pages exports properties across pages.

Download the four-property CSV
  1. Replace servicedesk in every row with your existing page API name. Keep the exported component name when updating a grid. A new name creates an instance of the installed component type.
  2. Choose Upload CSV in the page list, select the file and choose Validate CSV. Check the page layouts, changes and errors. If validation fails, use Download error report CSV to locate the row, fix the file and validate again.
  3. Choose Apply validated upsert. Open the affected draft layout, check the grid and publish it when ready. A blank layout field targets Desktop. Specify Tablet, Mobile or Custom explicitly when editing those drafts.

CSV quoting matters when the formula contains commas or double quotes. This is the card value row as it appears in the download.

servicedesk,smart_card_grid,PartsGrid,cardValue,"=""£"" & FORMAT(@Product.Price, ""0.00"")",Desktop

Check your result. With sample prices of 12.5 and 4.75, the tiles should show £12.50 and £4.75. If a tile is blank, compare the source object and field API names against your records. If the layout appears unchanged, confirm which device draft you applied and published.
