Review an open order

Select the line-item object, bind the item name and the quantity and amount columns, then set the subtotal expression. Check the result with two lines of different quantities.

Available properties

Select the component on the canvas, then select the part you want to style. Expand a group below to find the property label, its inventory CSV ID and its listed choices. Use the exported layout inventory to match the component instance when uploading changes.
