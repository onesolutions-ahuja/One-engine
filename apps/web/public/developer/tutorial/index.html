Build a sales forecast, schedule a service follow-up, or calculate a replenishment order. Try six editable expressions on sample records, then look up any function in the engine.

Write a display formula

Use @Object.Field to read the current row. Start a calculated expression with =, put text in double quotes, and separate function arguments with commas. For example, =ROUND(@Opportunity.Amount * 0.75, 0) returns a number. Wrap it in FORMAT when the UI needs formatted text.

Each case uses illustrative object and field API names. In Page Builder, bind the component to the matching records and enter the formula in its display property. Here, edit an expression and choose Run formula to preview both rows.
